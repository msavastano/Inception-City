# Assets

Almost everything in Inception City is made by code from a seed: the buildings, the streets, the sky, the sound, and the bodies and clothes of its people. This file lists the few things that are not, where they came from, and the licence they came under.

**The rule:** anything that is not generated here must be CC0 (public domain dedication) and must be listed in this file before it is merged. No likenesses of real people, no brand marks, no film music.

## Animation: Universal Animation Library (Standard), by Quaternius

| | |
| --- | --- |
| What | How people move: the skeleton and eleven motion clips |
| Author | [Quaternius](https://quaternius.com) |
| Licence | [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) (the pack's own `License.txt`) |
| Got from | `https://opengameart.org/sites/default/files/universal_animation_librarystandard.zip`, file `Godot/AnimationLibrary_Godot_Standard.glb` |
| In the repository as | [`src/people/rigdata.ts`](src/people/rigdata.ts), generated by [`scripts/pack-people.mjs`](scripts/pack-people.mjs) |

What was taken from the pack:

- **22 of its bones** (the body without fingers), with their rest pose.
- **Eleven clips**, resampled and quantised to 16 bits: `Idle_Loop`, `Idle_Talking_Loop`, `Walk_Loop`, `Walk_Formal_Loop`, `Jog_Fwd_Loop`, `Sprint_Loop`, `Jump_Loop`, `Jump_Land`, `Hit_Chest`, `PickUp_Table` and `Punch_Jab`.

What was not taken: the pack's mannequin mesh, its textures, and its other clips. The bodies in the game are built in code ([`src/people/body.ts`](src/people/body.ts)) on the pack's skeleton, so the pack itself (14 MB) is not in the repository and nothing is downloaded when the game runs. The packed data is about 60 kB.

To regenerate `src/people/rigdata.ts` (for instance to add a clip: edit the list at the top of the script):

```bash
node scripts/pack-people.mjs                 # downloads the pack into a cache folder
node scripts/pack-people.mjs path/to/pack.zip   # or use a copy you already have
```

The script also measures each walking clip: how fast it was animated to move, how far one cycle carries the walker, and where in the cycle the left foot lands. The game moves each clip on by the ground its walker covers, which is why feet do not slide.
